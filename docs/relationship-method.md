# 关系模块方法与参考审阅（0.4.0）

论文与适用边界完整列在 README。离线计算和云端深读是两条独立路径；未调用模型时不会联网。

## 计算契约

仅限一个有两位发言者的完整会话，先检查人数，再裁日期。以解析后的时间排序，分析时转换为显式时区（界面 UTC+8 或 UTC）。默认连续消息间隔达到 4 小时为新会话，可改 1/8/24 小时；同一会话连续同一发送者为一轮。第一条是左边界，不计算主动发起。

跨发送方且未超会话间隔的相邻轮替记录回复时延：上一轮最后一条 → 下一轮第一条。不按每个气泡重复计算。展示原始中位数、排除夜间后的中位数/四分位和 n；跨会话等待不在时延中，所以这不是所有等待时间。夜间排除判断整个等待区间是否与 23:00–08:00 相交，而非只看起点。没有已读状态，不能叫“已读不回”。

每个结束的轮次为对方提供一个接续机会：下轮由对方在间隔阈值内发出才记接续；否则要有完整阈值长的后续可观察历史才记一次未接续机会，末尾不足窗口不计；相交夜间的机会默认排除。它仍受分轮和窗口选择影响，不是对方拒绝你的比例。发起份额两人相加为 100%，不能当作各自独立的绝对好感值。

指数权重（接续50、发起30、分享20）仅为透明的产品启发式。每人至少30条、3个活跃日、5次接续机会且双方总共5次发起才显示；门槛也非统计验证的充分样本量。不提供伪精确置信区间。建议更改间隔/排除条件比较是否稳定，不能用一次分数判断关系。速度、支持/亲近词、宣泄不直接计分，避免词典错误或工作/睡眠习惯主导结论。

情感标签是小型中文词典，常见否定前缀/引语线索做有限排除，不能解决所有语法、反讽或上下文。每类最多展示12条原文，回复展示20对；计数覆盖全范围。事件扫描全范围，前200个候选可审核；用户可以补充漏检事件。月度表以本人当月消息数为分母。回忆界面最多100天、每天20条卡片，完整数据保留在文件及消息选择器。

## 参考项目审阅边界

参考仓库 UniUni2000/wechat-chat-analyzer，固定 commit `0bd27551ca686104d10e1ec7f296c9d7895eb4e0`，LICENSE 为 MIT。本次阅读 README、stats_engine.py 相关指标/采样实现及目录/依赖结构，没有复制代码或安装其 SKILL。

观察到上游使用5分钟间隔区分发起、统计相邻文本跨方间隔并排除超过24小时等待，包含均匀及高密度片段采样。本项目改用可配置间隔、合并连续轮次、明示截尾与夜间排除；离线统计不抽样，AI超限直接拒绝。不能把上游平均时差或画像提示词当作心理测量工具。

仓库包含 vendored 微信解密及 find_all_keys 代码，可能涉及进程内存与聊天密钥。未执行这些脚本，未做全仓依赖/供应链审计；**不能宣称该仓库整体安全**。仅采用分析层的组织想法，现有提取桥接独立保留。更没有把第三方 skill 当作模型可自动执行的插件。

## 语音与数据安全

faster-whisper 为可选源码扩展、安装版内置组件。固定1.2.1，通过构建环境安装二进制依赖；只接受本机模型目录，CPU INT8，local_files_only，无自动下载。模型权重不随 EXE 分发。WAV 通过标准库 wave 解码为数组，不让媒体容器解析器打开网络播放列表。限制20MB/10分钟/16kHz单声道PCM16；未支持微信SILK直接解码。没有调用真实用户音频验证识别率。

音频原件不改写，候选包含来源SHA256和分段时间。人工核对另存，有修订历史和乐观并发校验。关系报告含独立范围哈希，不包含API Key。HTTP接口继承原有Host/Origin/会话令牌校验，UI只以textContent呈现不可信内容。备份清单校验检测损坏，不提供加密或数字签名真实性保证。
