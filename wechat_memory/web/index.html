从 Windows 微信提取

    
  1. 在这台 Windows 电脑登录微信，并确认需要的聊天记录可在电脑端查看。
  2. 首次使用运行下载包中的 setup-windows.cmd，再运行 init-wechat-windows.cmd，按终端提示完成初始化。
  3. 检测环境、读取会话，选择要提取的对象。提取完成后自动保存为本地档案。

    
初始化可能需要管理员权限。仅提取本机可读取的消息，不自动发送给 AI；手机未迁移的历史和未下载的附件可能不在本机。首次初始化必须在 Windows 终端完成。

    
点击「检测环境」检查此电脑。Mac 上可继续导入已有文件，直接提取请在 Windows 运行。
